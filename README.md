# Shadow Ledger

Classements hebdomadaires, builds et guides pour *Solo Leveling: Arise* (POC, BOT, GB, HOTM), en français et en anglais.

- Site : https://shadowledgerhq.github.io (bientôt)
- YouTube, TikTok, X, Instagram : @shadowledger_hq

Projet de fan, non affilié à Netmarble. Données de builds avec l'autorisation de [SLAGATE](https://www.slagate.com/).

## Organisation du dépôt

| Dossier | Contenu |
| --- | --- |
| `data/` | Base de données du jeu, icônes, classements, builds |
| `pipeline/` | Scripts Python (recherche YouTube, OCR, exports) |
| `site/` | Site statique |
| `exports/` | Excel et PowerPoint générés |
| `videos/` | Scripts et storyboards des vidéos |
| `docs/` | Contexte du projet |
| `suivi/` | Avancement de chaque discussion |
