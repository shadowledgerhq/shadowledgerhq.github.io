# Icônes

- **Source** : slagate.com (Sohoven), images référencées par `GET api.slagate.com/api/references`, récupérées le 13/11/2026 avec l'accord d'Alexis (routes GET publiques, icônes comprises).
- **Droits** : les illustrations d'origine appartiennent à Netmarble / Solo Leveling: ARISE ; la mise en forme des images appartient à Slagate. Toute publication doit créditer Slagate.com (Sohoven). `robots.txt` de slagate.com indique `ai-train=no` : ne pas utiliser ces images pour entraîner une IA.
- **Format** : PNG 128×128, fond transparent, proportions conservées (outil : `tools/fetch_icons.py`).
- **Organisation** : `data/icons/<categorie>/<id>.png` ; pièces d'artefacts : `artifact_pieces/<id-du-set>--<emplacement>.png`.
- **Armes de Sung Jin-Woo sans icône Slagate (26)** : `data/icons/weapons/<id>.png`, fichiers « <nom> Icon.png » du wiki Fandom Solo Leveling: ARISE (texte du wiki CC BY-SA ; illustrations © Netmarble), récupérés le 17/11/2026, redimensionnés en 128×128 comme les autres ; source dans le champ `icon_source` de chaque entrée de `weapons.json`.
- **Cartes de référence** : `data/icons/hunters_cartes/esil-radiru.png` (recadrage de la capture POC `docs/essais/composition/poc_personnages_ja.png`, 17/11/2026) ; `data/icons/shadows_cartes/{beste,greed}.png` (mêmes captures, zones `shadows` de `etape2.json`). Pas de contrainte de droits au-delà de celle du jeu.
- **Armes de chasseurs (60)** : `data/icons/weapons/<id>.png`, fichiers « <nom> Icon.png » du wiki Fandom (CC BY-SA), 17/11/2026 ; `purple-butterflys-dream` = illustration de l'arme (pas d'icône dédiée). `icon_source` par entrée. Toutes les armes de la base ont maintenant une icône.
- **Puissances rémanentes (4 : Baran, Légia, Rockpasa, Yogmund)** : `data/db/remnant_powers.json`, icônes `data/icons/remnant_powers/` (128×128) et **cartes pleine taille** `data/icons/remnant_powers_cartes/` (illustration telle qu'affichée dans le jeu), source Slagate (`GET /api/references`, `passifsDeBoss`), 17/11/2026.
- **Cartes d'ombres (15)** : `data/icons/shadows_cartes/<id>.png`, recadrées le 17/11/2026 depuis deux captures du Codex du jeu (client FR, noms écrits sur chaque carte) fournies par Alexis ; remplacent les recadrages `beste`/`greed` du 17/11 (captures de composition). Correspondance nom FR → id : Avarice=greed, Ber=beru, Crâne=skull, Croc=tusk, Lames=blades, Igrit=igris, les autres identiques.
- **Cartes de chasseurs (55 ajoutées, `data/icons/hunters_cartes/<id>.png`)** : recadrées le 17/11/2026 depuis 5 captures du Codex des chasseurs d'Alexis (client FR, nom écrit sur chaque carte ; partie illustration, sans la barre de nom). Une carte = une tenue : `christopher-reed` et `esil-radiru` (apprises depuis la composition POC) n'ont pas été écrasées ; la carte POC n°3 (桐嶋玲奈) correspond à `jung-yerim` (82 correspondances contre 22 à ×2). Non présents au Codex : fern, frieren, minnie, miyeon, seorin, shuhua, soyeon, stark, yuqi. « Seo Lin » du Codex (non ajoutée : le nom diffère de `seorin`, à confirmer).
